# 武警学院教务需求规格

## 目标与范围
- 目标：将 Gibbon 定制为武警学院教务/训练管理平台，覆盖教务、教学、训练、行为奖惩、通知沟通、（可选）财务经费。
- 范围外：军械、后勤、独立安防系统等另行对接，不在本期实现。

## 用户与角色
- 核心用户：教务处管理员、学院教务员、任课教员、辅导员/班主任/学业导师、学员。
- 特殊用户：保卫/值班（应急广播）、财务经费审核（可选）、系统管理员。
- 角色策略：
  - Parent 角色仅占位，不创建账号、无菜单/权限；家长渠道禁用。
  - 角色命名：年级辅导员/主任、辅导员/班主任/学业导师（替换原年级组长/导师）。
  - 最小权限、可审计；公开注册禁用，所有高权限操作可追责。

## 组织模型与术语
- 层级：学院/系 → 专业 → 年级（届） → 班级（行政班/教学班）；可选分队/队别映射分组。
- 术语替换：Grade/Year Group→年级；Class/Form→班级（行政/教学班）；Tutor→辅导员/班主任/学业导师；可配置大队/中队叫法。
- 编码规范：学员学号/警号、教职工警号/工号唯一校验，导入/展示一致。

## 学籍与基础数据
- 学籍字段：籍贯、政治面貌、警号、入伍信息、体测等级等，可自定义扩展。
- 异动：休学、退学、留级、转专业、保留入学资格等需审批与留痕；离校/校友档案限权保留。
- 导入：学院/专业/年级/班级、学员、教员批量导入模板与校验（必填、唯一、编码规则）。

## 学年、课程、选课、排课
- 学年/学期（训练期）配置，符合教学+训练节奏。
- 课程：编码、学分/课时/周次、必修/选修、先修；课程类别涵盖军事/体能/专业。
- 选课：容量、年级/专业限制、优先级；可选审批链（教务→学院→教员）；变更通知自动化。
- 排课：场地/教官不可用时间冲突检测，训练场地占用约束；课表发布与变更通知；打印/导出含周次、场地、教官、班级。

## 考勤与训练
- 考勤类型：理论课、训练课、早操、晚点名；请假/销假（事假/病假/公差）审批流。
- 快捷记录：移动端/快速点名（早操、晚点名）。
- 异常提醒与报表：缺勤/迟到/未打卡自动通知；日/周/月报表导出。
- 训练成绩：体能/战术成绩录入与计算（合格/优秀/不合格），批量导入。

## 行为与奖惩
- 违纪类型与处分层级：记过/警告/留校察看等；审批链与打印模板（含签章位）。
- 奖励：与行为模块并存，权限受控。
- 事故/事件报告：用自定义表单或 Messenger 流程收集与流转。

## 通知与沟通
- 渠道：站内信、邮件、SMS（如有网关）；家长渠道禁用。
- 分发：按学院/年级/班级/队列推送；选课/排课/考勤异常/奖惩通知自动化。
- 模板：应急广播、处分/奖励通知等，限定可见人群。

## 扩展与集成推荐（官方 Extend）
- 官方扩展优先：Info Grid（角色化首页快捷入口）、Course Selection（选课规则）、Free Learning & Flexible Learning（自学/灵活学习单元）、Committees（委员会/小组管理，可选）、Crowd Assessment（互评，可选）、Moodle/在线课堂集成（如需对接 LMS）。
- 原则：先用官方扩展满足需求，若仍有缺口，再用自定义模块/页面补足。

## 安全与应急
- 报警改造：可关闭；如保留，改名“校园应急广播”，仅少数管理员/值班可用。
- 紧急联系人：带队教员、值班室字段，权限控制。
- 审计与认证：访问/操作日志，敏感导出受限；强密码，按需启用 2FA；SSO（AD/LDAP/CAS）视网络。

## 财务与经费（可选）
- 经费/报销：科目与类型（训练、教材、物资、差旅）；请购→审批→支付/入库。
- 缴费/罚款：违纪罚款、补证费用，权限受限；报表模板。

## 报表与导出
- 考勤、选课、排课、训练成绩、奖惩、经费等支持 CSV/PDF，按学院/年级/班级筛选。
- 打印模板：成绩单/评语、处分通知、应急广播、课表等。

## 集成与迁移
- 外部系统：可选 Moodle/在线课堂等；API 对接需权限与限流。
- 数据迁移：旧教务/Excel 字段映射，utf8mb4 清洗，小规模试导入。

## 信息发布与文档服务
- 公告/新闻：教务通知、教学运行/考试/选课变更公告，栏目发布，支持订阅/搜索。
- 规章制度库：上级/校内文件，综合管理/教务管理/实践创新/教研考评等分类，版本与附件下载。
- 手册与基本信息：学生/教师手册；专业设置、专业介绍、教学质量报告公示。
- 教学成果：专业建设、成果奖、教改项目、课程/教材建设、质量工程、创新创业项目等展示。
- 表格下载：学生（学籍学历、考试成绩、选课报名、毕设、创新、实习等）与教师资料分类，批量上传/下载与权限控制。
- 部门概况：教务处科室简介与联系方式（教学研究科、质量监控科、教学管理/运行/实践教学科、招生办等）。
- 服务导航：分角色入口（学生/教师/校友/公众），提供课程培养、选退课、考试成绩、课程评估、双专业/辅修、本科科研、推免、学籍异动、证件证明、出境/转学分、教室预约、课程表查询等指南与链接。
- 业务指南：按业务类型分步说明（选课规则、冲突/跨院系/超学分、退补选、重修/自修、考试缓考/纪律、学籍异动材料、证件补办/证明开具、教室借用/预约等）。
- 资源/链接聚合：学生服务中心、课程表查询、空闲教室、预约系统等外部入口集中展示。
- 警务院校特色栏目：通知公告、新闻动态、教学科研/实训、招生就业、警务技能与训练基地、队伍建设与思政/党建、继续教育/培训、校园文化等分类展示，支持搜索与多端访问。

## 非功能需求
- 可用性：桌面/移动端可用核心功能（选课/排课、考勤、通知）。
- 性能：排课/选课/考勤批量操作需达成约定 SLA（待量化）。
- 备份：数据库每日备份，uploads/config/compiled 定期备份与恢复演练。
- 配置可复用：角色/权限基线与术语替换可脚本化或清单化一键复现。
