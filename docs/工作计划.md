# 工作计划：Gibbon 适配武警学院教务需求

## 说明
- 目标：在最小改动核心代码的前提下，实现武警学院教务需求（见《武警学院教务需求规格》）。
- 原则：优先配置/扩展（术语替换、角色重命名、i18n/custom、官方扩展模块）而非改核心；自定义代码放在独立模块/资源目录，避免触碰 core。
- 结构建议：新建 `core/modules/PoliceCustom/` 承载业务扩展；文案在 `core/i18n/custom/`；样式/JS 覆盖在自定义主题或 `core/resources/custom/`；官方 Info Grid 等扩展直接安装在 `/modules/`。
- 顺序：按“高价值 + 低改动”优先，先配置与安全，再业务，再界面与集成。

## 目录/扩展策略（保持核心无侵入）
- 模块：`core/modules/PoliceCustom/`（自定义业务/页面/表单），官方扩展直接装在 `/modules/`。
- 文案：`core/i18n/custom/` + 后台术语替换。
- 样式/JS：自定义主题或 `core/resources/custom/`，避免改核心样式。
- 覆盖方式：Twig 继承/主题覆盖优先，不改核心 PHP；仅在极特殊情况下修改核心并记录。
- 配置清单：权限基线、术语清单、菜单清单存放 `core/docs/` 便于复现。
